# 🛠️ Projetos Simples de Cybersegurança

Esta pasta contém pequenos scripts em Python com foco em segurança digital, ideais para quem está iniciando na área.

## Scripts disponíveis:

### 🔐 1. Gerador de Senhas Fortes
Gera senhas seguras misturando letras, números e símbolos.

### 🕵️ 2. Verificador de Vazamento de E-mail
Simula uma checagem de e-mails vazados em listas conhecidas (pode evoluir com APIs).

### 📋 3. Verificador de Força de Senha
Avalia se a senha é fraca ou forte com base em critérios de segurança.
